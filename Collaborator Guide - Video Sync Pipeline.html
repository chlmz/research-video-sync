Overview

What this script does

In our research, each session is filmed by two wearable cameras — one worn by the mother and one by the child. Because the cameras are started manually, the two recordings are never perfectly aligned in time. This script automatically finds the time difference between the two videos and trims them so they start at exactly the same moment.

It processes your entire project folder at once, handling all participants in a single run, skipping anyone already processed, and generating a report of everything it did.

How it works

The pipeline, step by step

1

Scan the project folder

The script looks inside your project folder and finds every participant subfolder. It checks for a hidden .sync_done marker — if it's there, the participant was already processed and gets skipped. Only new folders are processed.

2

Find the two video files

Inside each participant folder it looks for a file containing _mom and a file containing _child in the filename. It accepts AVI, MP4, MOV, and MKV formats automatically.

3

Extract and analyze audio

It extracts the audio track from both videos and runs an FFT cross-correlation — a mathematical technique that compares the two audio waveforms across the entire recording to find the exact moment they overlap. This gives an offset in seconds, accurate to ~0.1 seconds.

4

Trim and export synced videos

Whichever camera started recording earlier gets its beginning trimmed by the exact offset. The result is two videos that start at the same real-world moment. Both are exported as MP4.

5

Create side-by-side video

A third file is created with both cameras playing simultaneously — mom's view on the left, child's view on the right. This is the main file used for behavioral coding and analysis.

6

Mark as done and update report

A hidden .sync_done file is placed in the participant folder so it won't be re-processed. A row is added to sync_report.csv with the participant ID, offset in seconds, status, and timestamp.

Setup — one time only

Installing the required tools

🍎 Mac

Open Terminal (Cmd+Space → Terminal) and run:

/bin/bash -c "$(curl -fsSL \ https://raw.githubusercontent.com/\ Homebrew/install/HEAD/install.sh)" brew install ffmpeg python3 pip3 install numpy \ --break-system-packages

If brew is not found after install, also run:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' \ >> ~/.zprofile && \ eval "$(/opt/homebrew/bin/brew shellenv)"

🪟 Windows

Install these three tools:

1. FFmpeg — download from ffmpeg.org and add to PATH

2. Python 3 — download from python.org

3. numpy — open Command Prompt and run:

pip install numpy

4. Git Bash — download from gitforwindows.org to run the script

✅ Verify your installation

Open Terminal (Mac) or Git Bash (Windows) and run ffmpeg -version and python3 --version. Both should return version numbers without errors.

Running the script

How to use it

Save sync_research_project.sh somewhere permanent on your computer (e.g. a Tools/ folder). Then make it executable — run this once in Terminal:

chmod +x /path/to/sync_research_project.sh

Then run it by pointing it at your project folder:

# Mac / Linux bash "/path/to/sync_research_project.sh" \ "/path/to/your/videos_project" # Windows (Git Bash) bash "/c/Users/you/Tools/sync_research_project.sh" \ "/c/Users/you/videos_project"

The script will print progress for each participant and show a popup when complete. Run it again anytime you add new participants — already-synced folders are skipped automatically.

Customization

What you may need to change

Open the script in any text editor. The only section you may need to edit is the Config block at the top (lines 20–23):

# ---- Config ---- MOM_PATTERN="_mom" # change if your mom files use a different suffix CHILD_PATTERN="_child" # change if your child files use a different suffix SYNCED_MARKER=".sync_done" # don't change this REPORT_NAME="sync_report.csv" # don't change this
Your file naming Set MOM_PATTERN to Set CHILD_PATTERN to

ID001_mae.avi "_mae" "_crianca"
ID001_madre.avi "_madre" "_nino"
ID001_mother.avi "_mother" "_infant"
cam1_ID001.avi "cam1" "cam2"

⚠️ Important — file naming rules

Each participant must have their own subfolder. Both video files must be inside that subfolder. The pattern you set must appear somewhere in the filename. The participant ID is taken from the folder name, not the filename.

Best practices

Tips for better sync accuracy

💡 Use a clap at the start of each recording

Have someone clap once loudly in front of both cameras at the start of each session. This creates a sharp audio spike that both microphones record simultaneously, giving the algorithm a perfect reference point. Accuracy improves from ~0.5s to ~0.05s. This is the industry standard and takes one second per session.

Other tips:

  • Keep original AVI files — the script never modifies them
  • If a sync result looks wrong, delete the .sync_done file in that participant's folder and re-run
  • The sync_report.csv file logs every offset — useful for documentation and quality control
  • You can run the script on the same folder from any computer that has access to it (e.g. via OneDrive)
  • Processing time: approximately 3–8 minutes per participant depending on video length and computer speed
