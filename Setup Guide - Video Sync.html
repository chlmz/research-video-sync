Step 1 — One-time setup

Install the tools

1

Open Terminal (Cmd + Space → Terminal)

2

Install Homebrew (if not already installed)

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
3

Install FFmpeg and Python

brew install ffmpeg python3
4

Save the script somewhere permanent

Move sync_videos.sh to a stable location, e.g. your Desktop or a Tools folder. Then make it executable:

chmod +x /path/to/sync_videos.sh
Step 2 — Using it with Cowork

Just tell Cowork what you want

Example prompts you can say to Cowork
"Sync these two videos: /Users/me/Downloads/camera1.mp4 and camera2.mp4 — use the sync_videos.sh script on my Desktop"
"Run sync_videos.sh on the two MP4 files in my Downloads folder"
"Find the two videos I downloaded today and sync them using the script in my Tools folder"

Cowork will locate the files, run the script, and tell you where the outputs were saved — all without you touching Terminal.

Tip: For even faster use, tell Cowork once: "Whenever I ask you to sync videos, use the sync_videos.sh script located at [your path]" — and it will remember for future tasks.
How it works

What happens under the hood

1

Audio extraction

Pulls the audio track from both videos as lightweight WAV files.

2

Cross-correlation analysis

Compares the two audio tracks mathematically to find the exact moment they match — down to ~10ms precision.

3

Smart trimming

Whichever video started recording later gets its beginning trimmed so both start at the same audio moment.

4

Three exports

Two individual synced MP4s + one side-by-side video, all saved in a timestamped folder next to your originals.

Output folder: Files are saved in a folder called synced_YYYYMMDD_HHMMSS/ right next to your first input video. Your originals are never touched.
